# Advanced Python Course

A practical, project-oriented course designed to develop Python skills from the fundamentals to automation, data visualization, object-oriented programming, and machine learning.

The course combines clear explanations, hands-on exercises, and practical workflows to help learners apply Python to real-world tasks.

## Course Overview

This course is organized into six chapters:

| Chapter | Topic | Main Focus |
|---|---|---|
| 1 | Python Fundamentals | Core syntax, data types, control flow, functions, and essential programming concepts |
| 2 | Python Programming, Automation & Reporting | Automating tasks, working with files and data, APIs, email workflows, and report generation |
| 3 | Advanced Excel with Python & Data Visualization | Excel automation, data analysis, and charts using Python, including Matplotlib |
| 4 | Project Planning with GanttProject | Planning, scheduling, and tracking project tasks using Gantt charts |
| 5 | Object-Oriented Programming (OOP) | Classes, objects, encapsulation, inheritance, and reusable program design |
| 6 | Introduction to Machine Learning | Preparing data, training models, evaluating results, and understanding machine-learning workflows |

## Course Curriculum

### Chapter 1 — Python Fundamentals

Build a strong foundation in Python programming before moving to more advanced applications.

Topics include:
- Introduction to programming and Python
- Setting up the Python environment and running code
- Variables, constants, and basic data types
- Operators and expressions
- Input and output
- Strings and common string operations
- Lists, tuples, sets, and dictionaries
- Conditional statements
- Loops and iteration
- Functions and reusable code
- Basic error handling and debugging
- Practical examples and exercises

**Learning outcome:** Write, understand, and debug small Python programs using fundamental programming concepts.

### Chapter 2 — Python Programming, Automation & Reporting

Use Python to automate repetitive tasks and connect different tools and services.

Topics and tools may include:
- Working with files and folders
- Reading, writing, and processing common file formats
- Automating repetitive tasks
- Data handling with **NumPy** and **Pandas**
- Sending and receiving emails programmatically
- Making HTTP requests and working with web APIs using **Requests**
- Handling JSON data and API responses
- Managing configuration and sensitive credentials safely
- Generating reports from processed data
- Organizing results into useful summaries and outputs
- Practical automation and reporting projects

**Learning outcome:** Build scripts that collect, process, and communicate information while reducing manual work.

### Chapter 3 — Advanced Excel with Python & Data Visualization

Combine Excel workflows with Python-based data analysis and visualization.

Topics and tools may include:
- Reading and writing Excel workbooks with **Pandas** and **OpenPyXL**
- Working with worksheets, rows, columns, and cell values
- Cleaning, transforming, filtering, and summarizing data
- Automating repetitive Excel operations
- Producing structured tables and reports
- Creating charts with **Matplotlib**
- Customizing titles, axes, legends, labels, and layouts
- Visualizing trends and comparing data
- Exporting analysis results for reporting
- Practical Excel automation and data-visualization exercises

**Learning outcome:** Automate spreadsheet workflows and turn raw data into clear tables, charts, and reports.

### Chapter 4 — Project Planning with GanttProject

Learn the fundamentals of project scheduling and visual task planning using GanttProject.

Topics include:
- Understanding projects, tasks, milestones, and dependencies
- Defining project activities and durations
- Organizing tasks and schedules
- Building and reading Gantt charts
- Assigning resources and responsibilities
- Identifying task dependencies and potential scheduling conflicts
- Monitoring progress against a plan
- Exporting and presenting project plans

**Learning outcome:** Create and communicate a structured project schedule using GanttProject.

> GanttProject is a project-planning tool included in the course to complement the technical programming chapters.

### Chapter 5 — Object-Oriented Programming (OOP)

Learn how to structure Python programs using objects and reusable components.

Topics include:
- Procedural programming versus object-oriented programming
- Classes and objects
- Attributes, methods, and constructors
- The `self` parameter and instance behavior
- Encapsulation and data organization
- Inheritance and method overriding
- Polymorphism
- Composition and reusable design
- Special methods and readable object representations
- Organizing code into modules
- Practical OOP exercises and mini-projects

**Learning outcome:** Design programs that are more organized, maintainable, and easier to extend.

### Chapter 6 — Introduction to Machine Learning

Explore the core workflow of machine learning with Python.

Topics and tools may include:
- What machine learning is and where it is used
- Supervised and unsupervised learning
- Preparing, cleaning, and exploring datasets
- Selecting features and defining target variables
- Splitting data into training and test sets
- Training baseline machine-learning models
- Classification and regression concepts
- Model evaluation and appropriate metrics
- Avoiding data leakage and understanding overfitting
- Interpreting results and communicating findings
- Practical exercises using Python data-science libraries

**Learning outcome:** Understand and implement a basic machine-learning workflow, from preparing data to evaluating a model.

## Getting Started

1. Install a supported version of Python.
2. Install Jupyter Notebook or use an environment that supports `.ipynb` files.
3. Clone or download this repository.
4. Open the relevant chapter notebook.
5. Follow the explanations in order and run the code cells.
6. Complete the exercises and modify the examples to test your understanding.

For a typical Python environment, you can install common libraries with:

```bash
python -m pip install jupyter numpy pandas matplotlib openpyxl requests scikit-learn
```

Some chapters may require additional setup. Email automation and external APIs may also require service-specific configuration and credentials. Never commit passwords, API keys, tokens, or other secrets to a public repository.
